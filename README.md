SalemBot - Freqtrade on Railway
================================

خطوات التشغيل:

1) GitHub: سوّ مستودع خاص (Private) باسم salem-bot
   وأضف الملفات الأربعة تحت بنفس المسارات بالضبط
   (Add file > Create new file، واكتب المسار كامل مثل user_data/strategies/SalemTrend.py)

2) Railway: سجّل بحساب GitHub > New Project > Deploy from GitHub repo > salem-bot

3) Settings > Region: اختر EU West (Amsterdam)
   لا تختار أمريكا، لأن Binance يحجب السيرفرات الأمريكية

4) أضف Volume وخلّ مساره: /data

5) Variables (المتغيرات) حسب المرحلة:

   المرحلة 1 - اختبار تاريخي:
     MODE = backtest
   النتيجة تطلع في Deploy Logs. صوّرها وأرسلها لي.

   المرحلة 2 - تداول وهمي (أسبوعين) - هذا الوضع الافتراضي لو ما حطيت MODE:
     MODE = dryrun
     TG_TOKEN = توكن البوت من @BotFather
     TG_CHAT_ID = رقمك من @userinfobot

   المرحلة 3 - تداول حقيقي:
     MODE = live
     BINANCE_KEY = مفتاح API
     BINANCE_SECRET = المفتاح السري
   مفتاح Binance: فعّل Spot Trading فقط، واقفل السحب (Withdrawals)

مهم: البوت يتداول بكل رصيد USDT الموجود في الحساب.
حط في الحساب (أو حساب فرعي) المبلغ اللي تبي البوت يتداول فيه بس.

أوامر تيليجرام:
  /status   الصفقات المفتوحة
  /profit   الأرباح
  /stopentry  يوقف الدخول في صفقات جديدة
  /forceexit all  يقفل كل الصفقات
  /stop     يوقف البوت

صياد الانفجارات SalemPump (حقيقي أو وهمي)
================================
يشتغل لحاله (SalemTrend موقف، يرجع بـ SALEMTREND = on). يدخل العملات اللي تبدأ تنفجر ويركب الموجة.
- يتداول بـ 50$ بس (PUMP_CAPITAL)، 3 صفقات كحد أقصى
- يفحص كل عملات USDT اللي حجمها 10 مليون$+ باليوم:
  العملة الكبيرة (BTC ETH SOL...) 25$، والعملة الصغيرة 10$، وعملتين صغيرتين كحد أقصى بالوقت
- ما يدخل إذا السبريد (الفرق بين سعر البيع والشراء) أكثر من 0.3%
- إذا خسر 5$ في يوم يوقف الدخول لين بكرا
- أي ربح فوق 50$ ما يدخل صفقات ثانية ويبقى في حسابك USDT تسحبه وقت ما تبي
- إذا نزل رصيد التداول إلى 30$ (60%) يوقف الدخول في صفقات جديدة ويبلغك
- يدخل لما عملة: تطلع 2.5%+ في 15 دقيقة، وحجمها 4 أضعاف المعتاد، وتكسر قمة آخر ساعتين،
  والبتكوين مو طايح
- ما يدخل متأخر: إذا طلعت 6%+ في 15 دقيقة أو 18%+ في اليوم
- يخرج: وقف خسارة -4% | وقف متحرك بعد +4% (2.5% تحت القمة، 4% بعد +7%، 6% بعد +10%) |
  ما كمّل الانفجار خلال 45 دقيقة | ما جت موجة خلال ساعتين

متابعة عملاتك (حقيقي فقط):
- أي عملة في Spot قيمتها 5$ أو أكثر ما اشتراها البوت (قديمة أو جديدة) يستلمها خلال دقيقة
  ويتابعها بوقف خسارة -4% ووقف متحرك بعد +4% (بدون قواعد الوقت)
- العملة الجديدة: الوقف من سعر شرائك. العملة القديمة: الوقف من سعرها يوم استلمها
- يرسل نظرته عليها (صاعد/هابط/عرضي، ربحك، رأيه) لما يستلمها وكل 6 ساعات
- مبلغها برا الـ 50$ حقت البوت. عملات Alpha وSimple Earn ما يقدر يتابعها

تنبيهات بوت الزخم:
- أضف بوت التنبيهات وبوت كلاود كريبتو مشرفين في قناة خاصة، وخل بوت التنبيهات ينشر فيها
  (أو حوّل التنبيه يدوياً لبوت كلاود كريبتو)
- يطلع اسم العملة من الرابط (مثل LUMIA_USDT) ويفحصها: مو متأخرة (24س < 18%، 15د < 6%)،
  الزخم حي (15د +1%+ وحجم 2× المعتاد)، سيولة 10 مليون$+، سبريد < 0.3%، البتكوين مو طايح، والحدود
- يرد عليك: ✅ دخلت أو ❌ ما دخلت مع الأسباب

التشغيل الحقيقي (Railway Variables):
  PUMP_LIVE = on
  BINANCE_KEY = ...      (مفتاح: Spot Trading فقط، السحب مقفول)
  BINANCE_SECRET = ...
  لا تحط MODE = live (هذا يشغّل SalemTrend حقيقي بكل رصيد الحساب)
متغيرات اختيارية: GRID = off يوقفه | PUMP_CAPITAL = 50 | PUMP_TG_HOURLY = off
(كود بوت الشبكة القديم باقي في grid/grid_bot.py)
